# S03 engineering learning review

Recorded 2026-10-25 under ADR-024 (the agent maintains CLAUDE.md and the skills) and the [knowledge policy](../../docs/07-developer-workflow/REUSABLE-KNOWLEDGE-POLICY.md). Each lesson below was reproduced during S03. None widens authority, access roots, external data transfer, paid operations, product scope or game canon. Runtime memory and game canon are untouched.

| ID | Lesson | Evidence | Outcome |
|---|---|---|---|
| S03-L01 | Anthropic refuses tool schemas with top-level `anyOf`, `oneOf` or `allOf`. In strict mode it also refuses `maxItems`, length, pattern and numeric bounds, nested combinators and `not`, each with HTTP 400 at no cost. The host keeps validating the full closed schema, and the adapter sends a conditioned copy and drops `strict` for tools that need combinators | Four live refusals while recording (`tools.3.custom: For 'array' type, property 'maxItems' is not supported`, `input_schema does not support oneOf, allOf, or anyOf at the top level`, `Schema type 'oneOf' is not supported`, `Schema keyword 'not' is not supported`). Tests `strict_mode_gets_a_conditioned_schema` and `top_level_combinators_are_never_sent` in `crates/agent/src/anthropic.rs` | Applied: code, tests, CLAUDE.md "Agent runtime rules". Version bound: Anthropic API `2026-10-21`, `claude-haiku-5-5` |
| S03-L02 | A lease must outlive any single step, so it needs a background heartbeat, and the heartbeat must be tied to its owner by an abort-on-drop guard | `a_native_run...` first failed with `fenced` (1 s test TTL, longer turn). After the heartbeat, `an_interrupted_write...` failed because an aborted runner's heartbeat kept the dead incarnation's lease alive | Applied: runner heartbeat with `AbortOnDrop`, CLAUDE.md |
| S03-L03 | `tokio::select!` polls branches in random order. With a pending cancel, the turn was sometimes never sent and the supervisor killed an idle worker | `a_cooperative_worker_stops_when_asked` failed 2 of 3 runs with `killed after 1 ms`, and a biased select fixed it (4 of 4, then the suite 6 of 6) | Applied: a biased select in the runner, CLAUDE.md |
| S03-L04 | Answers combining several tables need one `REPEATABLE READ` snapshot, and an attempt's end and its task's next state commit in one transaction | Detail route showed `cancelled` attempt with `running` task (READ COMMITTED, two statements) | Applied: `AgentRuntime::snapshot`, single-transaction finish, CLAUDE.md |
| S03-L05 | Pause defers a turn's tool calls. Refusing them lost the effect on resume | `a_pause_survives_a_restart...` wrote zero files after resume | Applied: pending calls run after the boundary checks, CLAUDE.md |
| S03-L06 | Ledger hash columns accept only real SHA-256. Absence is `None` in the receipt and `"absent"` in the artifact | Receipt settlement failed silently (logged) until fixed | Applied: runner and recovery mapping, CLAUDE.md |
| S03-L07 | A container whose PID 1 is our binary never reaps orphans, so a killed process group leaves zombies | `shutdown_kills_the_whole_process_group` failed only on Linux in Docker | Applied: `init: true` for the server service, `--init` in `scripts/linux-tests.sh`, zombie-aware test, CLAUDE.md |
| S03-L08 | Worker test faults go through the launcher's environment, never the test process's, because tests in one binary run in parallel | Design decision while writing the W6 tests | Applied: `WorkerLauncher::env`, CLAUDE.md |
| S03-L09 | Agent Tools needs Node 22 or 24 and refuses a symlinked state directory (macOS temp dirs), while Setup needs Debian's Node 18 | Reported by the W5 packet agent, image build and real-tool tests | Applied: two Node runtimes in the image, `prepare_state_dir`, CLAUDE.md |
| S03-L10 | Parallel crate packets merge cleanly when the parent commits empty crate skeletons first, writes the integration API into each brief (saved as a file the agent reads), and keeps cross-crate composition for itself | Four Sonnet packets (agent, tasks, broker, hoi4-tools) plus the web packet merged without conflicts | Applied: CLAUDE.md delegation section and the `delegate-parallel-work` skill |
| S03-L11 | A host schema the broker cannot enforce is withheld silently unless logged and tested | `agent_tools_decision_inspect` was missing from the live tool list (keyed maps in its schema) | Applied: narrowed schema, warning log, regression test `every_agent_tools_profile_schema_is_enforceable_by_the_broker` |

No candidate was rejected. Copies regenerated with `scripts/py.sh scripts/sync_skills.py --write`, and `--check` reports no drift. The knowledge changelog records the guidance changes.
