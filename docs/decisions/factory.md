| D-61 | 2026-11-14 | Which S04 focus editor design is chosen? | None of the four (A to D). All of them show too much. The focus editor is as minimal as possible, because agents handle most of the work and the modder mostly looks, asks and approves. It has no manual layout fields such as column or position numbers, and it does not show things a modder will rarely touch or care about. New, much simpler variants are built in the design lab for the maintainer to choose from. This tightens D-51, and the live game preview of D-50 stays the main element. The four change card designs are set aside the same way, and simpler change card variants are built under the same rules. Maintainer decision |
| D-63 | 2026-11-14 | Which minimal S04 designs are chosen? | The focus editor is the full-page game render of the tree with one ask bar for the agent. Direct editing stays: the modder drags a focus to move it and clicks one to get a small card with its title, description and cost. The change card shows one full-page picture of the final result, one sentence that says what changed, and Approve and Reject. It has no before and after comparison, because the maintainer finds that unnecessary and wants only the final result shown. The final designs are mockups 110 to 113 in the design lab. D-50, D-51 and D-61 still apply. Maintainer decision |
| D-64 | 2026-11-14 | May the S04 server be extended for the chosen page designs? | Yes, with both additions the design session asked for. A new attempt of an edit task may carry a follow-up instruction from the modder, so the ask bar can talk to the agent inside its task. A focus operation changes the title, the description or both of an existing focus, shared by the editor and the agent. Both get server tests on Linux before they merge. Maintainer decision |
| D-66 | 2026-11-14 | How does the S04 editor link to trees, and how does it handle the time an edit takes? | The server gets a small read-only route that lists a mod's focus trees, so the task page can link to any tree and not only to one that already has a proposal. An edit takes about two seconds in the tools even after the speed work, against a one second target. The editor therefore shows the change at once and confirms it when the tool's check has finished, and it shows clearly when a change was refused. The tools keep their safe write and their check. Maintainer decision |
