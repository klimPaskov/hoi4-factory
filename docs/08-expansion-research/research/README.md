# Research appendices

These are the working reports from the Phase A research on 2026-10-31, kept so a later agent can continue without repeating the research. Each was written by a research subagent that read actual source at pinned revisions, and was reviewed by the parent session before use. They are plain text with Markdown formatting and are not held to the package prose rules. Claims carry evidence labels such as verified, documented, inferred and unverified, as each report explains at its top.

Material from the maintainer's private repositories was removed from these copies (decision D-01). Hagane Works material is paraphrased with file and line references.
